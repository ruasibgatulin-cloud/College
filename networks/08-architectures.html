8Сетевые архитектуры и технологии

Каждая сетевая технология — это набор правил: как передавать, на какой скорости, на каком уровне. Здесь собраны основные стандарты от Ethernet до 5G.

8.1. Ethernet (IEEE 802.3)

Самая распространённая технология проводных локальных сетей. Работает на канальном уровне (2).

Скорости Ethernet

Формат Ethernet-кадра

Ethernet-кадр: 14 байт заголовка + данные + 4 байта контрольной суммы.

8.2. Wi-Fi (IEEE 802.11)

Беспроводная технология. Работает на канальном уровне (2), но через радиоканал.

Режимы работы

  • Infrastructure — клиенты подключаются к точке доступа (обычный Wi-Fi).
  • Ad-Hoc — устройства соединяются напрямую, без точки доступа.
  • Mesh — несколько точек доступа создают единую сеть.

Проблемы Wi-Fi

  • Помехи — микроволновки, соседские сети, Bluetooth работают в 2.4 ГГц.
  • Затухание — стены, мебель, вода снижают сигнал.
  • Разделение среды — все клиенты делят пропускную способность точки доступа.
  • Безопасность — WEP устарел, WPA2 минимальный, WPA3 рекомендуется.

Стандарты безопасности

СтандартГодСтойкость

WPA2003Устарел
WPA2 (PSK / Enterprise)2004Стандарт, но есть атаки
WPA32018Современный стандарт

8.3. Token Ring (IEEE 802.5)

Историческая технология IBM. Устарела, но интересна как альтернатива Ethernet.

  • Топология: кольцо.
  • Метод доступа: маркер (token). Передавать может только владелец маркера.
  • Скорости: 4 и 16 Мбит/с.
  • Плюс: нет коллизий, предсказуемая задержка.
  • Минус: дорого, сложно, обрыв кольца ломает сеть.
  • Проиграла Ethernet — проще и дешевле.

8.4. FDDI (Fiber Distributed Data Interface)

Оптическая технология кольца, развивавшая идеи Token Ring.

  • Скорость: 100 Мбит/с.
  • Среда: оптоволокно.
  • Отказоустойчивость: два кольца, при обрыве используется резервное.
  • Дальность: до 200 км (для магистралей).
  • Устарела с приходом Gigabit Ethernet.

Выделенные линии (Leased Line)

Постоянное соединение между офисами компании с гарантированной полосой. Используется в корпоративной среде.

  • SDH/SONET — оптические магистрали 10+ Гбит/с.
  • MPLS — виртуальные частные сети между офисами.
  • Ethernet Line (E-Line) — L2-канал между двумя точками через провайдера.

8.6. VPN — виртуальные частные сети

VPN (Virtual Private Network) — защищённый туннель через публичную сеть.

Зачем нужен VPN

  • Удалённый доступ сотрудников к корпоративной сети.
  • Соединение офисов через интернет (site-to-site VPN).
  • Шифрование трафика — защита от перехвата в публичных Wi-Fi.
  • Смена IP — обход географических ограничений.

Основные протоколы VPN

ПротоколУровеньОсобенности

WireGuard — современный стандарт
В отличие от OpenVPN и IPsec, WireGuard написан заново с нуля — всего 4000 строк кода. Работает в ядре Linux, очень быстрый, простой в настройке. Активно используется в корпоративных и личных VPN.

SSH — золотой стандарт

# Подключение к серверу
ssh user@192.168.1.100
ssh -p 2222 user@example.com    # на нестандартном порту

# С ключом
ssh -i ~/.ssh/id_rsa user@example.com

# Генерация ключа
ssh-keygen -t ed25519 -C "my email"
# Публичный ключ копируется на сервер
ssh-copy-id user@example.com

# Проброс портов
ssh -L 8080:localhost:80 user@example.com
# Теперь локально http://localhost:8080 = удалённый порт 80
SSH используется для управления серверами, передачи файлов, проброса портов.

Практические задания

🎯 ПР №12 · Беспроводная сеть с WPA2 45 мин
Задача: настроить Wi-Fi-сеть с защитой в miminet (если поддерживается) или описать процесс для реального роутера.
  1. Если у вас есть роутер дома:
    • Зайдите в панель управления (обычно 192.168.1.1 или 192.168.0.1).
    • Найдите раздел Wireless.
    • Запишите: SSID, канал, тип шифрования, пароль.
    • Смените канал на другой (например, с 6 на 11) — проверьте, изменилась ли скорость.
    • Не меняйте пароль, если не хотите заново подключать устройства.
  2. Или в miminet: если есть модуль Wi-Fi, соберите схему с точкой доступа и 3 клиентами.
  3. Проверьте: клиенты видят друг друга, могут пинговать.
Результат: скриншот панели роутера + отчёт о параметрах Wi-Fi.
🎯 ПР №13 · Удалённое подключение через SSH 45 мин
Задача: настроить SSH-доступ к Linux-машине.
  1. Если у вас Linux (или WSL):
    • Установите OpenSSH: sudo apt install openssh-server
    • Запустите: sudo systemctl start ssh
    • Проверьте: sudo systemctl status ssh
    • Узнайте свой IP: ip a
  2. С другого компьютера в той же сети подключитесь: ssh user@192.168.1.100
  3. Сгенерируйте SSH-ключ: ssh-keygen -t ed25519
  4. Скопируйте ключ на сервер: ssh-copy-id user@192.168.1.100
  5. Проверьте, что вход по ключу работает без пароля.
Результат: скриншоты успешного подключения + отчёт.

Вопросы для самопроверки

Вопрос 1. Почему Ethernet победил Token Ring и FDDI?
Проще, дешевле, быстрее развивался.

  • Простота. Ethernet — общая шина или звезда с коммутатором. Token Ring требовал сложной логики маркера.
  • Стоимость. Ethernet-оборудование дешевле в производстве и монтаже.
  • Открытый стандарт. Ethernet — IEEE 802.3, доступен всем. Token Ring — изначально технология IBM, менее открытая.
  • Скорость развития. Ethernet быстро прошёл путь 10 Мбит → 100 Мбит → 1 Гбит → 10 Гбит. Token Ring застрял на 16 Мбит.
К 2000-м Ethernet полностью вытеснил конкурентов.
Вопрос 2. Чем WPA2 отличается от WPA3?
WPA2 (2004) — долгое время был стандартом. Использует шифрование AES-CCMP. Уязвим к атакам KRACK (2017) и перебору пароля по handshake (PMKID).

WPA3 (2018) — современный стандарт:
  • SAE (Simultaneous Authentication of Equals) — защита от перебора пароля (даже слабого).
  • Forward Secrecy — если пароль утек, ранее переданные данные всё равно нельзя расшифровать.
  • Шифрование в открытых сетях (OWE) — даже в кафе трафик защищён.
  • 192-битное шифрование для корпоративных сетей.
Рекомендуется везде, где поддерживается (Wi-Fi 6+).
Вопрос 3. Зачем нужен VPN, если HTTPS и так шифрует?
HTTPS защищает содержимое страницы, но не всю поездку данных.

Что видно без VPN (даже с HTTPS):
  • Провайдер видит, к каким сайтам вы обращаетесь (по IP и SNI).
  • Локальная сеть в кафе видит те же IP и, если нет HTTPS, всё содержимое.
  • Рекламные сети строят профиль по вашим запросам.
  • Географические ограничения — сайт не открывается из вашей страны.
VPN решает:
  • Шифрует весь трафик до VPN-сервера.
  • Скрывает от провайдера, куда вы идёте.
  • Меняет видимый IP-адрес.
  • Позволяет подключаться к корпоративной сети из дома.
Вопрос 4. Чем 5G отличается от 4G?
Параметр4G LTE5G
Скорость (пик)1 Гбит/с20 Гбит/с
Задержка20-30 мс1-5 мс
Плотность устройств100 000 / км²1 млн / км²
Частотыдо 6 ГГцдо 40 ГГц (mmWave)
Применение 5G:
  • Автономные автомобили (низкая задержка).
  • IoT в промышленности (миллионы датчиков).
  • VR/AR-стриминг (высокая пропускная способность).
  • Умные города.
Минус: mmWave плохо проходит через стены, поэтому нужны базовые станции каждые 100-300 метров.
