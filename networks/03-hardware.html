3Аппаратные компоненты компьютерных сетей

Сеть — это не только кабели. Это устройства, каждое из которых выполняет свою роль. Понимание разницы между ними — основа сетевой грамотности.

3.1. Сетевой адаптер (NIC)

NIC (Network Interface Card) — плата или чип, который соединяет устройство с сетью.

  • Есть у каждого сетевого устройства: компьютер, телефон, принтер, камера.
  • Имеет уникальный MAC-адрес (48 бит, вида 00:1A:2B:3C:4D:5E).
  • Может быть проводным (Ethernet) или беспроводным (Wi-Fi).
  • Работает на канальном уровне (уровень 2 OSI).
# Windows
ipconfig /all
getmac

# Linux
ip link show
ifconfig -a
cat /sys/class/net/eth0/address
Просмотр MAC-адресов сетевых адаптеров.

3.2. Концентратор (Hub)

Хаб — устаревшее устройство. Работает на физическом уровне (1).

  • Просто повторяет сигнал на все порты.
  • Все устройства в одном домене коллизий — одновременно может говорить только один.
  • Не запоминает адреса — не знает, кому идёт кадр.
  • Устарел с появлением коммутаторов (2000-е).

3.3. Коммутатор (Switch)

Свитч — устройство канального уровня (2). Главное устройство современной LAN.

  • Хранит таблицу MAC-адресов: какой MAC на каком порту.
  • Отправляет кадр только на нужный порт.
  • Каждый порт — отдельный домен коллизий.
  • Поддерживает full-duplex — передача в обе стороны одновременно.

Как коммутатор учит MAC-адреса

  1. Приходит кадр от устройства с MAC AA:AA через порт 3.
  2. Коммутатор записывает: «MAC AA:AA → порт 3» в таблицу.
  3. Смотрит MAC-получателя в кадре. Если знает, на каком порту — отправляет туда. Если нет — рассылает на все (flooding).
  4. Через несколько секунд таблица заполнена, flooding больше не нужен.
Коммутатор ведёт таблицу MAC-адресов и не рассылает кадры всем подряд.

3.4. Маршрутизатор (Router)

Роутер — устройство сетевого уровня (3). Соединяет разные сети.

  • Работает с IP-адресами, а не MAC.
  • Имеет таблицу маршрутизации: куда отправлять пакеты для разных сетей.
  • Определяет маршрут до получателя — через какие сети и устройства пойдёт пакет.
  • Домашний роутер = маршрутизатор + коммутатор + точка доступа + NAT + firewall.
# Windows
route print
tracert 8.8.8.8

# Linux
ip route show
traceroute 8.8.8.8
Просмотр таблицы маршрутизации и маршрута до сервера.

3.5. Шлюз (Gateway)

Шлюз — «выход» из одной сети в другую. Обычно это интерфейс роутера.

  • Когда устройство не знает, куда отправить пакет (получатель в другой сети) — отправляет на шлюз.
  • Шлюз по умолчанию (default gateway) указывается в настройках TCP/IP.
  • Обычно адрес шлюза — .1 в подсети: 192.168.1.1.

3.6. Точка доступа (Access Point)

Устройство, которое позволяет подключаться по Wi-Fi. Работает на канальном уровне (2).

  • Соединяет беспроводных клиентов с проводной сетью.
  • Имеет SSID (имя сети) и настройки безопасности (WPA2/WPA3).
  • Домашний роутер обычно содержит встроенную точку доступа.

3.7. Модем

Устройство для преобразования сигнала между разными средами: аналоговый ↔ цифровой, оптический ↔ электрический.

  • DSL-модем: телефонная линия ↔ цифровой интернет.
  • Кабельный модем: коаксиальный ТВ-кабель ↔ интернет.
  • Оптический терминал (ONT): оптика ↔ Ethernet.
  • 4G/5G-модем: сотовая сеть ↔ Ethernet/Wi-Fi.

Практическое задание

🎯 ПР №3 · Сеть с маршрутизатором 45 мин
Задача: собрать сеть с двумя подсетями и настроить маршрутизацию в miminet.
  1. Откройте miminet.ru, создайте новый проект.
  2. Разместите:
    • 4 хоста (Host)
    • 2 коммутатора (Switch)
    • 1 маршрутизатор (Router)
  3. Схема: 
    Host1, Host2 → Switch1 → Router → Switch2 → Host3, Host4
  4. Настройте IP-адреса:
    • Сеть A (LAN1): 10.0.0.0/24
      Router: 10.0.0.1, Host1: 10.0.0.10, Host2: 10.0.0.11
    • Сеть B (LAN2): 10.0.1.0/24
      Router: 10.0.1.1, Host3: 10.0.1.10, Host4: 10.0.1.11
  5. Укажите шлюзы на хостах (адрес роутера в своей сети).
  6. Проверьте: ping 10.0.1.10 с Host1.
  7. Запустите traceroute 10.0.1.10 — увидите, что пакет идёт через роутер 10.0.0.1.
Результат: скриншот успешного ping + traceroute. Сохраните JSON-файл проекта.

Вопросы для самопроверки

Вопрос 1. Зачем нужен коммутатор, если есть роутер?
У них разные задачи.

Коммутатор — соединяет устройства внутри одной сети (LAN). У него много портов (8-48), но он не умеет связывать разные сети.

Роутер — соединяет разные сети. Портов у него обычно мало (4-5), зато он умеет маршрутизировать.

Пример: в офисе 40 компьютеров. Роутер имеет 4 LAN-порта — их не хватит. Ставят коммутатор на 48 портов, а роутер — как выход в интернет.
Вопрос 2. Что произойдёт, если два коммутатора соединить двумя кабелями?
Возникнет петля (loop) — пакеты начнут бесконечно циклиться между коммутаторами, загружая сеть на 100% и вызывая широковещательный шторм.

Решение: протокол STP (Spanning Tree Protocol). Коммутаторы обмениваются BPDU-сообщениями, выбирают корневой коммутатор, а лишние связи блокируют. Если основной путь упадёт — резервный автоматически активируется.

В современных коммутаторах STP включён по умолчанию — это одна из причин, почему реальные сети работают стабильно.
Вопрос 3. Как домашний роутер делает столько всего в одной коробке?
Внутри обычного домашнего роутера — несколько устройств:
  • Маршрутизатор — связывает LAN с WAN провайдера.
  • Коммутатор — 4 LAN-порта.
  • Точка доступа Wi-Fi — раздаёт беспроводную сеть.
  • NAT — подменяет приватные IP на один публичный.
  • DHCP-сервер — раздаёт IP клиентам.
  • DNS-прокси — кэширует DNS-запросы.
  • Firewall — фильтрует трафик.
  • Модем — если встроен, для подключения к телефонной/кабельной линии.
Всё это — на одном чипе с прошивкой Linux. Отсюда и название «роутер», хотя по сути это «швейцарский нож» для сети.
Вопрос 4. Где применяется оптический терминал ONT?
ONT (Optical Network Terminal) — «модем» для оптоволоконных линий (GPON, XPON). Устанавливается, когда провайдер заводит оптику прямо в квартиру или офис.

Задачи:
  • Преобразует оптический сигнал в электрический (Ethernet).
  • Иногда встроен в роутер (ONT + router).
  • Поддерживает VLAN, IPTV, VoIP.
В России популярен у провайдеров Ростелеком, МГТС, Билайн (технология GPON). Симметричные скорости до 1 Гбит/с.
