6Численное решение дифференциальных уравнений

Дифференциальное уравнение (ДУ) — уравнение, содержащее производную неизвестной функции. Обыкновенные ДУ (ОДУ) — производная только по одной переменной.

Задача Коши: найти функцию $y(x)$, удовлетворяющую уравнению

$$y' = f(x, y)$$

и начальному условию $y(x_0) = y_0$.

Геометрически: зная точку и «направление движения» (производную), шаг за шагом строим график решения.

6.1. Метод Эйлера

Идея: заменяем производную конечной разностью:

$$y' \approx \frac{y_{i+1} - y_i}{h}.$$

Отсюда:

$$y_{i+1} = y_i + h \cdot f(x_i, y_i).$$

Простейший метод. Погрешность $O(h)$. Накапливается с каждым шагом — можно «уехать» от истинного решения.

Метод Эйлера «идёт» по касательным. При большом шаге отклоняется от точного решения.

6.2. Уточнённая схема Эйлера (метод Хойна)

Идея: на каждом шаге усредняем наклон в начале и в конце шага.

  1. Предсказание: $\tilde y_{i+1} = y_i + h \cdot f(x_i, y_i)$.
  2. Уточнение: $y_{i+1} = y_i + \dfrac{h}{2}\left[f(x_i, y_i) + f(x_{i+1}, \tilde y_{i+1})\right]$.

Погрешность $O(h^2)$ — точнее обычного Эйлера.

6.3. Метод Рунге-Кутты 4-го порядка

Стандарт де-факто. На каждом шаге вычисляет функцию 4 раза в разных точках, комбинирует с весами.

$$k_1 = f(x_i, y_i),$$ $$k_2 = f(x_i + h/2, y_i + h \cdot k_1 / 2),$$ $$k_3 = f(x_i + h/2, y_i + h \cdot k_2 / 2),$$ $$k_4 = f(x_i + h, y_i + h \cdot k_3),$$ $$y_{i+1} = y_i + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4).$$

Погрешность $O(h^4)$ — на порядок точнее Эйлера при том же шаге.

Метод Эйлера для y' = y − x, y(0) = 1. Точное решение: y = x + 1. Ползунок меняет число шагов.

Реальный кейс: физика в Unity
Когда персонаж прыгает в игре, движок решает ДУ: $y'' = -g$ (ускорение свободного падения). Интегрируется численно.

Unity использует полу-неявный метод Эйлера (PBD, Position-Based Dynamics) для жёстких тел. Для ткани и волос — метод Верле. Для мягких тел — Рунге-Кутта. Выбор метода зависит от того, что важнее: скорость (60 fps) или точность. В играх почти всегда побеждает скорость.
Устойчивость vs точность
Метод может быть точным (мало ошибок на одном шаге), но неустойчивым — ошибки растут от шага к шагу, пока решение не «взорвётся». В играх часто используют не самые точные, но устойчивые методы (полу-неявный Эйлер).

Практическая работа №11

🔧 ПР №11 · Методы Эйлера и Рунге-Кутты 60 мин
Задача: решить задачу Коши численно тремя методами.

Уравнение: $y' = y - x$,   $y(0) = 1$,   шаг $h = 0{,}5$, интервал $[0, 2]$.

Точное решение: $y = x + 1$ (проверьте подстановкой).

Часть 1. Метод Эйлера

  1. Составьте таблицу: $i$, $x_i$, $y_i$, $f(x_i, y_i) = y_i - x_i$.
  2. Выполните 4 шага до $x = 2$.
  3. Сравните с точным решением.

Часть 2. Уточнённый Эйлер (Хойн)

  1. На каждом шаге сначала вычисляйте предсказание $\tilde y$, потом уточнение.
  2. Сделайте 4 шага.
  3. Погрешность должна быть меньше, чем у обычного Эйлера.

Часть 3. Программирование

Напишите функцию solve_ode(f, x0, y0, x_end, h), реализующую метод Рунге-Кутты 4-го порядка. Протестируйте на том же уравнении.

# Метод Рунге-Кутты 4 порядка
def rk4(f, x0, y0, x_end, h):
    x, y = x0, y0
    while x < x_end:
        k1 = f(x, y)
        k2 = f(x + h/2, y + h*k1/2)
        k3 = f(x + h/2, y + h*k2/2)
        k4 = f(x + h, y + h*k3)
        y += h/6 * (k1 + 2*k2 + 2*k3 + k4)
        x += h
    return y
Результат: таблицы расчёта двумя методами + скриншот программы.

Вопросы для самопроверки

Вопрос 1. Почему метод Эйлера накапливает погрешность?
На каждом шаге мы заменяем кривую касательной — это даёт локальную ошибку $O(h^2)$. Но шагов много, и ошибки складываются.

Итоговая погрешность на всём интервале — $O(h)$. При уменьшении шага в 2 раза ошибка тоже падает в 2 раза (не в 2²) — это первый порядок точности.

Исключение: если функция $f(x, y) = f(x)$ (не зависит от $y$), метод Эйлера совпадает с методом прямоугольников — точность чуть лучше.
Вопрос 2. Что такое «жёсткая система» ДУ и почему для неё методы плохо работают?
Жёсткая система — когда есть процессы с сильно разными скоростями (например, одна переменная меняется за $10^{-6}$ секунды, другая за 1 секунду).

Явные методы (Эйлер, РК4) вынуждены брать очень маленький шаг, чтобы не «взорваться» на быстрой переменной — даже если интересна медленная динамика.

Решение: неявные методы (неявный Эйлер, методы Гира, Розенброка). Они сложнее на каждом шаге, но шаг может быть в тысячи раз больше.

Пример жёсткой системы — химическая кинетика: одни реакции за наносекунды, другие за минуты.
Вопрос 3. Почему в играх не используют Рунге-Кутту для физики?
Скорость. РК4 вызывает функцию 4 раза на шаг. Для 1000 объектов, 60 fps — это 240 000 вызовов в секунду только на физику. Полу-неявный Эйлер — 60 000.

Стабильность при большом шаге. Полу-неявный Эйлер устойчив лучше, чем явный Эйлер, при том же размере шага. Для визуальных эффектов «прыгает похоже на настоящее» — этого достаточно.

Простота. В физику встроены ограничения (коллизии, связи), которые в явных методах проще интегрировать.

Исключение: в кинематографической анимации, где точность важнее, могут использовать и РК4.
