5Численное интегрирование

Задача: вычислить $\int_a^b f(x)\,dx$, когда первообразная не выражается через элементарные функции или функция задана таблицей.

Геометрический смысл: площадь криволинейной трапеции под графиком.

5.1. Метод прямоугольников

Идея: разбиваем интервал на $n$ частей. На каждом маленьком отрезке площадь кривой приближаем прямоугольником.

Формула (левых прямоугольников):

$$S \approx h \cdot \sum_{i=0}^{n-1} f(x_i), \quad h = \frac{b-a}{n}.$$

Погрешность: $O(h)$ — уменьшили шаг в 2 раза, погрешность тоже в 2 раза.

5.2. Метод трапеций

Идея: на каждом отрезке аппроксимируем кривую прямой, площадь считаем как площадь трапеции.

$$S \approx \frac{h}{2}\left[f(x_0) + 2\sum_{i=1}^{n-1} f(x_i) + f(x_n)\right].$$

Погрешность: $O(h^2)$ — точнее прямоугольников.

Метод трапеций: чем больше n, тем точнее площадь. Синяя кривая — $f(x) = 0{,}5 x^2 + 1$. Точное значение интеграла на $[0, 3]$ = 7,5.

5.3. Метод Симпсона (парабол)

Идея: на каждой паре отрезков функцию заменяем параболой (многочленом 2-й степени). Точнее всех предыдущих.

$$S \approx \frac{h}{3}\left[f(x_0) + 4\sum_{нечёт} f(x_i) + 2\sum_{чёт} f(x_i) + f(x_n)\right].$$

Требование: $n$ — чётное.

Погрешность: $O(h^4)$ — очень точный. Для многочленов до 3-й степени даёт точный результат при любом $n$.

5.4. Метод Гаусса

Идея: вместо равномерных узлов выбирают специальные точки (узлы Гаусса-Лежандра), где функция учитывается с разными весами. Даёт высокую точность при малом $n$.

Для $n=2$ (два узла) точность сопоставима с методом Симпсона при $n=4$.

ОбластьПример

Реальный кейс: рендер освещения
В 3D-графике есть задача глобального освещения: чтобы посчитать цвет точки на поверхности, нужно проинтегрировать вклад света со всех направлений полусферы. Это интеграл по 2D-области.

Аналитически его посчитать нельзя (сцена слишком сложная), а метод Монте-Карло — разновидность численного интегрирования — справляется. Каждая точка изображения 1920×1080 = 2 миллиона интегралов. За кадр. При 60 fps — 120 миллионов в секунду.

Практическая работа №10

🔧 ПР №10 · Численное интегрирование 60 мин
Задача: вычислить интеграл тремя методами и сравнить точность.

Интеграл: $\displaystyle\int_0^1 x^2\,dx$. Точное значение: $1/3 \approx 0{,}3333\ldots$

Часть 1. Метод прямоугольников

  1. Разбейте интервал на $n = 4$ отрезка ($h = 0{,}25$).
  2. Вычислите $f(x) = x^2$ в точках $x_0 = 0, x_1 = 0{,}25, x_2 = 0{,}5, x_3 = 0{,}75$.
  3. Сложите и умножьте на $h$.
  4. Сравните с точным $1/3$. Найдите погрешность.

Часть 2. Метод трапеций

  1. Используйте те же $n = 4$.
  2. Примените формулу трапеций.
  3. Сравните погрешность с прямоугольниками.

Часть 3. Метод Симпсона

  1. Примените формулу Симпсона при $n = 4$.
  2. Так как $f(x) = x^2$ — многочлен 2-й степени, Симпсон должен дать точный результат.
  3. Проверьте это.

Часть 4. Программирование (по желанию)

Напишите функцию для метода трапеций. Протестируйте на интеграле $\int_0^1 e^{-x^2}\,dx$ (это интеграл ошибок, аналитически не берётся). Эталонное значение: 0,7468.

Вопросы для самопроверки

Вопрос 1. Почему метод Симпсона точнее метода трапеций?
Метод трапеций заменяет кривую прямыми, а метод Симпсона — параболами. Парабола может «прогнуться» вслед за кривой, поэтому приближение точнее.

Формально: погрешность трапеций $O(h^2)$, погрешность Симпсона $O(h^4)$. При уменьшении $h$ в 10 раз погрешность трапеций падает в 100 раз, Симпсона — в 10 000 раз.
Вопрос 2. Какой метод выбрать для интеграла от табличных данных?
Если данные заданы только в точках — метод трапеций. Он естественно работает с таблицей: между соседними точками проводим прямые.

Симпсон требует равноотстоящих узлов и чётного числа отрезков — тоже подходит, если данные с равномерным шагом.

Метод Гаусса требует знания функции в специальных точках — для табличных данных не подходит.
Вопрос 3. Почему метод Монте-Карло — это тоже численное интегрирование?
Идея Монте-Карло: чтобы посчитать площадь области, «бросаем» случайные точки в ограничивающий прямоугольник и считаем долю попавших внутрь.

Математически это оценка интеграла: $\int_a^b f(x)\,dx \approx (b-a) \cdot \bar{f}$, где $\bar{f}$ — среднее по случайным точкам.

Плюс: работает в любом измерении. Для 3D, 4D, 10D-интегралов (а в графике и ML их много) метод прямоугольников требует $n^d$ узлов, а Монте-Карло — всего $\sqrt{n}$ точек. Для $d = 10$ разница в миллионы раз.

Минус: сходится медленно — $O(1/\sqrt{n})$.
