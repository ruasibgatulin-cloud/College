8Компьютерная графика

Компьютерная графика — область информатики, занимающаяся созданием и обработкой изображений с помощью компьютера.

8.2. Растровая vs векторная

Растровая графика «рассыпается» при увеличении. Векторная остаётся гладкой.

8.3. Разрешение и размер

  • Разрешение — количество пикселей по горизонтали × по вертикали: 1920×1080, 3840×2160 (4K).
  • PPI (pixels per inch) — плотность пикселей. Для экранов достаточно 72-96 PPI, для печати — 300 PPI.
  • DPI (dots per inch) — плотность точек печати.
Пример расчёта
Хотите напечатать фото 10×15 см при 300 PPI.
10 см = 3,94 дюйма → 3,94 × 300 = 1181 пиксель по ширине
15 см = 5,91 дюйма → 5,91 × 300 = 1772 пикселя по высоте
Итог: изображение не менее 1181 × 1772.

Практические работы №18-19

🔧 ПР №18 · Работа в графическом редакторе 50 мин
Задача: освоить базовые операции в GIMP или Photopea.

Часть 1. Открытие и основы

  1. Откройте Photopea (photopea.com) — работает в браузере бесплатно, без установки.
  2. Загрузите любое фото через File → Open.
  3. Изучите интерфейс: панель инструментов слева, панель слоёв справа, меню сверху.
  4. Попробуйте инструменты: Move (перемещение), Crop (обрезка), Brush (кисть), Eraser (ластик).

Часть 2. Обрезка и масштаб

  1. Обрежьте фото до квадрата инструментом Crop.
  2. Измените размер: Image → Image Size, установите 800×800 px.
  3. Сохраните результат: File → Export As → JPG, качество 80%.

Вопросы для самопроверки

Задача 1. Логотип компании нужно напечатать на футболках и баннерах. Какой формат использовать?
Векторный (SVG, AI, EPS, PDF). Причины:
  • Логотип масштабируется без потери качества — от визитки до билборда.
  • Печать требует высокого разрешения; вектор даёт максимальное.
  • Можно легко менять цвета, размеры, шрифты.
Растровый (PNG, JPG) подойдёт только для мелких форматов или если логотип не будет увеличиваться.
Задача 2. Фото весит 8 МБ. Как уменьшить размер файла для сайта?
Способы:
  1. Изменить размер — 4000×3000 px не нужен для веба. Уменьшить до 1200×900 px.
  2. Сжать — сохранить в JPG с качеством 70-80% (Photoshop: «Сохранить для Web»).
  3. Сменить формат — на WEBP: часто меньше на 30-50% при том же качестве.
  4. Убрать метаданные (EXIF с координатами, моделью камеры) — иногда экономит десятки КБ.
Итого: из 8 МБ легко сделать 150-300 КБ без видимой потери качества.
Задача 3. Чем PNG отличается от JPG?
JPG:
  • Сжатие с потерями — при сильном сжатии появляются «артефакты».
  • Нет прозрачности.
  • Хорош для фотографий.
  • Маленький размер файла.
PNG:
  • Сжатие без потерь — качество идеальное.
  • Поддерживает прозрачность (alpha-канал).
  • Хорош для логотипов, скриншотов, графики с текстом.
  • Размер больше, чем JPG.
Правило: фото — JPG, логотип с прозрачностью — PNG, современный веб — WEBP.
Задача 4. В чём разница между RGB и CMYK?
RGB — аддитивная модель: смешение света. Красный + зелёный + синий = белый. Используется на экранах.

CMYK — субтрактивная модель: смешение красок. Голубой + пурпурный + жёлтый + чёрный. Используется в печати.

Почему важно: цвета, которые ярко смотрятся на экране (например, насыщенный синий), при печати могут оказаться тусклыми. Профессиональный подход — работать в RGB, но перед печатью конвертировать в CMYK и проверять цвета.
