3Текстовый процессор — продвинутый уровень

3.1. Списки

Список — структурированная запись однотипных элементов. Три типа:

  • Маркированный — символы ●, ■, ♦, –
  • Нумерованный — 1., 2., 3. или a), b), c)
  • Многоуровневый — вложенные списки с отступами
Пример многоуровневого списка
1. Основные виды ИТ
   a. Текстовые
   b. Табличные
   c. Графические
2. Сферы применения
   • Офис
   • Образование
   • Промышленность

Горячие клавиши:

  • Tab — понизить уровень (вложить)
  • Shift+Tab — повысить уровень
  • Enter — новый элемент
  • Enter дважды — выйти из списка

3.2. Стили

Стиль — сохранённый набор форматирования. Применил стиль — все настройки разом. Главное: изменение стиля меняет всё оформление сразу.

СтильПрименяется
Заголовок 1Главные разделы документа (например, «Введение», «Глава 1»)
Заголовок 2Подразделы внутри главы
Заголовок 3Более мелкое дробление
ОбычныйОсновной текст
ЦитатаВыделенные цитаты
НазваниеЗаголовок титульного листа
Зачем стили
Стили автоматически строят оглавление и область навигации. Если оформлять заголовки вручную (просто крупным шрифтом), оглавление работать не будет.

Создание собственного стиля

  1. Отформатируйте абзац как надо.
  2. Выделите его.
  3. В панели стилей: «Создать стиль» → задать имя → сохранить.

3.3. Оглавление

Автоматическое оглавление строится из абзацев со стилями «Заголовок 1, 2, 3…».

Как создать:

  1. Примените стили ко всем заголовкам.
  2. Поставьте курсор в место, где будет оглавление (обычно после титульного листа).
  3. Меню: Ссылки → Оглавление → Автособираемое.
  4. Готово. При изменении заголовков — обновить (F9 или кнопка «Обновить таблицу»).

3.4. Колонтитулы

Колонтитул — область в верхнем или нижнем поле страницы, повторяющаяся на каждой странице (или в пределах раздела).

  • Верхний — обычно название работы или главы
  • Нижний — обычно номер страницы
  • Могут быть разными для чётных/нечётных страниц
  • Могут различаться по разделам (например, титульный лист без номера)
Типичный вариант
  • Титульный лист — без колонтитулов
  • Оглавление — римские цифры (i, ii) или без нумерации
  • Основной текст — арабские цифры внизу по центру

3.5. Сноски и примечания

  • Сноска — внизу страницы, пояснение к слову
  • Концевая сноска — в конце документа
  • Примечание (комментарий) — не печатается, только для работы в команде

Как добавить сноску: поставить курсор после слова → Ссылки → Вставить сноску → набрать текст сноски внизу страницы.

Горячая клавиша: Ctrl+Alt+F — обычная сноска, Ctrl+Alt+D — концевая.

3.6. Разрывы страниц и разделов

3.7. Титульный лист

Обычно оформляется по шаблону учебного заведения. Основные элементы:

  • Название учебного заведения (вверху)
  • Тип работы (реферат, курсовая, отчёт) — по центру
  • Тема работы
  • ФИО студента, группа
  • ФИО проверяющего
  • Город и год (внизу)

3.8. Список литературы

Оформляется по ГОСТ Р 7.0.5-2008. Типичная запись книги:

Пример
Иванов, И. И. Программирование на Python : учебник / И. И. Иванов. — 3-е изд., перераб. и доп. — Москва : Юрайт, 2023. — 420 с.

Ссылки на интернет-ресурсы:
Название сайта : официальный сайт. — URL: https://example.com (дата обращения: 01.10.2026).

Практические работы №6-8

🔧 ПР №6 · Списки и стили 40 мин
Задача: освоить списки всех типов и стили заголовков.
  1. Создайте новый документ.
  2. Наберите заголовок «Мои любимые ИТ» — примените стиль «Заголовок 1».
  3. Создайте маркированный список из 5 программ, которыми пользуетесь.
  4. Создайте нумерованный список из 3 разделов ИТ.
  5. Внутри одного из пунктов сделайте вложенный список через Tab.
  6. Добавьте второй заголовок «Стили в действии» — стиль «Заголовок 2».
  7. Проверьте область навигации (Вид → Область навигации): оба заголовка должны появиться.
🔧 ПР №7 · Оглавление и колонтитулы 40 мин
Задача: построить автособираемое оглавление и настроить колонтитулы.
  1. В документе из ПР №6 добавьте 3-4 заголовка со стилями «Заголовок 1/2».
  2. Поставьте курсор в начало документа (после пустой страницы) — вставьте оглавление через Ссылки → Оглавление.
  3. Вставьте нижний колонтитул с номером страницы: Вставка → Номер страницы → Внизу по центру.
  4. В верхнем колонтитуле — название работы через Вставка → Верхний колонтитул.
  5. Проверьте: на титульной странице не должно быть номера (галочка «Особый колонтитул для первой страницы»).
  6. Добавьте на любую страницу обычную сноску: Ctrl+Alt+F.
🔧 ПР №8 · Титульный лист и список литературы 40 мин
Задача: оформить титульный лист по стандарту и список литературы.
  1. Создайте новую страницу в начале документа (ПР №6-7).
  2. Оформите титульный лист:
    • Вверху по центру: «АНО ПОО ММКЦТ "Академия ТОП"»
    • По центру: «ОТЧЁТ по дисциплине "Информационные технологии"»
    • Ниже: «Тема: Работа с текстовым процессором»
    • Справа: «Выполнил: студент группы … ФИО»
    • Внизу по центру: «Москва, 2026»
  3. В конце документа создайте раздел «Список литературы» (стиль «Заголовок 1»).
  4. Оформите 5 источников по ГОСТ: 2 книги, 2 интернет-ресурса, 1 учебник.
  5. Обновите оглавление: F9 или кнопка «Обновить таблицу».
  6. Сохраните в .docx и .pdf.

Вопросы для самопроверки

Задача 1. Как изменить сразу все заголовки «Заголовок 1» во всём документе?
  1. В панели стилей найдите «Заголовок 1».
  2. Правый клик → «Изменить».
  3. Задайте новый шрифт / цвет / размер.
  4. Подтвердите — все «Заголовки 1» в документе обновятся.
Оглавление тоже можно обновить через F9.
Задача 2. Что произойдёт, если удалить заголовок из документа, а оглавление не обновить?
В оглавлении останется «мёртвый» пункт. При клике — переход в никуда.

Решение: правый клик по оглавлению → «Обновить поле» → «Обновить целиком». Word пересоберёт список.
Задача 3. В чём разница между сноской и колонтитулом?
Сноска — привязана к конкретному слову/фразе. Появляется внизу той страницы, где стоит метка. Не повторяется.

Колонтитул — область в поле страницы, повторяется на всех страницах раздела. Содержит номер страницы, название главы, логотип.
Задача 4. Как сделать, чтобы на титульной странице не было номера, а на остальных — был?
Двойной клик на нижний колонтитул → откроется «Работа с колонтитулами».
Вариант 1 (простой): в панели «Параметры» поставить галочку «Особый колонтитул для первой страницы» — тогда на 1-й странице номер не ставится.

Вариант 2 (правильный для многостраничных работ): создать разрыв раздела после титульного листа (Макет → Разрывы → Со следующей страницы), а во втором разделе включить нумерацию, отключив «Как в предыдущем разделе».
