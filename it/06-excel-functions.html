6.2. Функция IF (ЕСЛИ)

Синтаксис
=IF(условие; значение_если_истина; значение_если_ложь)

Вложенные IF:

=IF(A1>=90; "отлично"; IF(A1>=75; "хорошо"; IF(A1>=60; "удовлетворительно"; "неуд")))
Оценка по баллу: 90+ отлично, 75+ хорошо, 60+ удовл., иначе неуд.

IF + AND / OR:

=IF(AND(A1>=60; B1>=60); "Зачёт"; "Не зачёт")
Зачёт, если оба балла ≥ 60.

6.3. COUNTIF и AVERAGEIF

=COUNTIF(A1:A100; ">100")           # сколько значений > 100
=COUNTIF(B1:B100; "Москва")           # сколько ячеек содержат "Москва"
=AVERAGEIF(A1:A100; ">50"; B1:B100)   # среднее B по строкам, где A > 50
Условные подсчёты и средние.

Несколько условий — используйте COUNTIFS и AVERAGEIFS:

=COUNTIFS(A:A; "Москва"; B:B; ">1000")
Сколько строк, где в A «Москва», а в B больше 1000.

6.4. VLOOKUP (ВПР)

Ищет значение в первом столбце таблицы и возвращает значение из другого столбца той же строки.

Синтаксис
=VLOOKUP(что_искать; где_искать; номер_столбца; режим)
  • что_искать — значение (например, артикул товара)
  • где_искать — диапазон таблицы
  • номер_столбца — из какого столбца возвращать
  • режим — FALSE (точное совпадение) или TRUE (приблизительное)
=VLOOKUP(A1; Sheet2!A:C; 3; FALSE)
Найти значение из A1 в столбце A листа Sheet2, вернуть значение из 3-го столбца.
Ограничения VLOOKUP
  • Ищет только в первом столбце диапазона.
  • Возвращает только справа от ключевого столбца.
  • Не работает, если таблица поменяет структуру.
Альтернатива: INDEX+MATCH — работает в любом направлении:
=INDEX(B:B; MATCH(A1; A:A; 0))

6.6. Сводные таблицы

Сводная таблица (Pivot Table) — инструмент для быстрой агрегации больших данных. Позволяет за пару кликов получить итоги по категориям, посчитать среднее, суммы, количество.

Как построить:

  1. Выделить исходную таблицу.
  2. Меню: Вставка → Сводная таблица.
  3. Выбрать место размещения (новый лист или существующий).
  4. В панели справа перетащить поля:
    • Строки — категории (например, «Город»)
    • Столбцы — дополнительная категоризация (например, «Месяц»)
    • Значения — что считать (например, «Сумма продаж»)
    • Фильтры — фильтр всей таблицы (например, «Год»)

6.7. Макросы и VBA

Макрос — записанная последовательность действий, которую можно запустить одной командой.

VBA (Visual Basic for Applications) — встроенный язык программирования Excel для автоматизации.

Как записать макрос:

  1. Включить вкладку «Разработчик»: Файл → Параметры → Настроить ленту.
  2. Разработчик → Запись макроса.
  3. Задать имя, назначить горячую клавишу.
  4. Выполнить действия (например, отформатировать выделенные ячейки).
  5. Разработчик → Остановить запись.
Файлы с макросами
Сохранять нужно в формате .xlsm (Excel Macro-Enabled). Стандартный .xlsx не сохраняет VBA-код.

🔧 ПР №14 · Сводные таблицы и макросы 50 мин
Задача: освоить сводные таблицы и записать простой макрос.

Часть 1. Сводная таблица

  1. Создайте таблицу 50+ строк: Дата, Город, Товар, Количество, Сумма.
  2. Вставьте сводную таблицу: Вставка → Сводная таблица.
  3. Разместите:
    • В строках — Город
    • В столбцах — Товар
    • В значениях — Сумма (Сумма по полю)
  4. Добавьте фильтр по Дате (например, только 1-й квартал).
  5. Поменяйте агрегацию: посчитайте не сумму, а количество — правый клик по полю → «Параметры поля» → «Количество».

Часть 2. Макрос

  1. Включите вкладку «Разработчик».
  2. Разработчик → Запись макроса → имя FormatHeader, горячая клавиша Ctrl+Shift+H.
  3. Выделите шапку таблицы → сделайте жирной, залейте цветом, выровняйте по центру.
  4. Остановите запись.
  5. Проверьте: перейдите на другой лист, выделите другую таблицу, нажмите Ctrl+Shift+H — макрос применит форматирование.
  6. Сохраните файл в формате .xlsm.

Вопросы для самопроверки

Задача 1. Найти среднее по столбцу A, но только для значений больше 10. 
=AVERAGEIF(A1:A100; ">10")
В русской локали Excel: =СРЗНАЧЕСЛИ(A1:A100; ">10").
Задача 2. Чем отличается VLOOKUP от INDEX+MATCH?
VLOOKUP:
  • Ищет только в первом столбце диапазона.
  • Возвращает значения только справа.
  • При добавлении столбца слева — все ссылки «ломаются».
INDEX+MATCH:
  • Ищет в любом столбце.
  • Возвращает из любого направления.
  • Не ломается при изменении структуры таблицы.
  • Работает быстрее на больших данных.
Если Excel 365 — используйте XLOOKUP: он объединяет преимущества обоих.
Задача 3. Как сделать сводную таблицу, где строки — месяцы, столбцы — товары, а значения — среднее количество?
  1. Выделить исходные данные.
  2. Вставка → Сводная таблица.
  3. Перетащить поля:
    • «Месяц» → в область «Строки»
    • «Товар» → в область «Столбцы»
    • «Количество» → в область «Значения»
  4. В области «Значения» правый клик по полю «Количество» → «Параметры поля значений» → выбрать «Среднее».
Задача 4. Почему макросы не работают в файле .xlsx?
Формат .xlsx не хранит VBA-код (из соображений безопасности). При сохранении файла с макросом в этом формате Excel предупредит, что код будет потерян.

Нужно сохранять как .xlsm (Excel Macro-Enabled Workbook). Он поддерживает макросы и открывается обычным Excel — но при первом запуске может попросить разрешить макросы.
