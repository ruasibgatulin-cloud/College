7Программа подготовки презентаций

Программа для создания слайд-шоу, которые показываются с экрана: PowerPoint, Google Slides, Keynote, LibreOffice Impress.

7.1. Назначение и структура презентации

Презентация помогает донести идею, удержать внимание, наглядно показать данные. Хорошая презентация — не «стены текста», а опора для докладчика.

Структура (классическая)

  1. Титульный слайд — тема, автор, дата
  2. Введение — зачем это, 1-2 слайда
  3. Основная часть — 3-5 смысловых блоков
  4. Выводы — 1-2 слайда
  5. Контакты / Спасибо

7.2. Правила хорошего слайда

  • 1 слайд = 1 мысль. Не пытайтесь уместить всё.
  • Правило 7×7: не более 7 строк, не более 7 слов в строке.
  • Крупный шрифт: минимум 24 пт для текста. Заголовки — 32-40 пт.
  • Единый стиль: 2-3 цвета, 1-2 шрифта на всю презентацию.
  • Изображения > текст. Схема, график, фото работают лучше абзаца.
  • Контраст. Тёмный текст на светлом фоне (или наоборот).
Смертный грех презентации
Читать вслух то, что написано на слайде. Аудитория читает быстрее, чем вы говорите. Оставьте на слайде ключевые тезисы, а детали рассказывайте голосом.

7.3. Макеты и разметка

Макет слайда — предустановленная структура: заголовок + текст, заголовок + два столбца, только заголовок, пустой слайд.

МакетКогда использовать
Титульный1-й слайд
Заголовок и содержимоеОсновной текст, списки
Два содержимогоСравнение «до / после», «плюсы / минусы»
Только заголовокКрупная картинка или схема
ПустойПолная свобода компоновки
СравнениеДва блока с подписями

7.4. Работа с текстом

  • Текстовый блок — прямоугольник с пунктирной рамкой. Можно перетаскивать и растягивать.
  • Списки делаются через кнопку «Маркеры» на вкладке «Главная».
  • Не более 5-6 пунктов в списке на слайде.
  • Ключевые слова выделяйте жирным или цветом.
  • Шрифты без засечек (Arial, Calibri) читаются лучше, чем с засечками.

7.5. Изображения

  • Вставка → Рисунки — локальные файлы, стоковые, онлайн.
  • Формат рисунка → Обрезка — обрезать лишние части.
  • Сжатие изображений — уменьшает вес файла (Файл → Сжать рисунки).
  • Убрать фон — встроенный инструмент удаления.
  • Не растягивайте маленькие картинки — они станут размытыми.

7.6. Анимация

Анимация — появление / исчезновение / движение объекта внутри слайда.

Переход — эффект между слайдами (например, «Появление», «Растворение»).

Тип анимацииКогда использовать
ПоявлениеОбъект входит на слайд
ВыделениеПривлечь внимание к уже видимому объекту
ВыходОбъект исчезает
Пути перемещенияДвижение объекта по траектории
Правило анимации
Анимация должна помогать, а не отвлекать. «Летающие по слайду коты» — это плохо. Плавное появление списка пункт за пунктом во время доклада — хорошо.

7.7. Мультимедиа

  • Видео: Вставка → Видео → С компьютера / Из интернета.
  • Аудио: фоновая музыка или комментарии (лучше не злоупотреблять).
  • Запись экрана: Вставка → Запись экрана.
  • Дикторская нарезка: Вставка → Звук → Записать звук.

7.8. Гиперссылки и управляющие кнопки

  • Гиперссылка — переход на другой слайд, файл или сайт.
  • Управляющая кнопка — готовая фигура-стрелка для навигации: «Домой», «Далее», «Назад».

7.9. Подготовка к показу

  • Режим докладчика (F5): на вашем экране — текущий слайд, следующий, заметки, таймер; на проекторе — только текущий.
  • Заметки к слайду: печатаются отдельно, аудитория их не видит.
  • Репетиция: инструмент «Показ слайдов → Репетиция» засекает время.

7.10. Экспорт

ФорматКогда
.pptxРабочий файл (можно редактировать)
.pdfРассылка, гарантированное отображение
.mp4Видеоролик с озвучкой и анимацией

Практические работы №15-17

🔧 ПР №15 · Создание презентации 50 мин
Задача: создать презентацию «Моя будущая профессия» из 8-10 слайдов.
  1. Откройте PowerPoint. Выберите тему оформления из встроенных.
  2. Слайд 1 (титульный): название, автор, группа, дата.
  3. Слайд 2: план презентации (маркированный список).
  4. Слайды 3-7: по одной теме на слайд (например, «Плюсы профессии», «Инструменты», «Зарплаты» и т.д.).
  5. Слайд 8: выводы (2-3 тезиса).
  6. Слайд 9: «Спасибо за внимание» + контакты.
  7. Вставьте 3+ изображения на разные слайды.
  8. Примените единый стиль шрифтов и цветов.
🔧 ПР №16 · Анимация и мультимедиа 40 мин
Задача: оживить презентацию — добавить анимацию и видео.
  1. Откройте презентацию из ПР №15.
  2. На слайде с планом настройте появление пунктов по одному при клике (Анимация → Появление → По клику).
  3. На один из слайдов добавьте короткое видео: Вставка → Видео → Из интернета (или с компьютера).
  4. Настройте переходы между слайдами: переход «Растворение» на всю презентацию.
  5. Проверьте в режиме показа (F5), что всё работает.
🔧 ПР №17 · Управляющие кнопки и экспорт 30 мин
Задача: добавить навигацию и подготовить файлы к сдаче.
  1. Вставьте в нижний угол каждого слайда (кроме титульного) управляющие кнопки: «Домой», «Назад», «Далее».
  2. На слайде с планом сделайте гиперссылки с каждого пункта — на соответствующий слайд.
  3. Отрепетируйте: Показ слайдов → Репетиция. Уложитесь в 5 минут.
  4. Экспортируйте в PDF: Файл → Экспорт → Создать PDF.
  5. Экспортируйте в видео: Файл → Экспорт → Создать видео (если доступно).
  6. Сдайте оба файла: .pptx и .pdf.

Вопросы для самопроверки

Задача 1. В презентации 20 слайдов, все с текстом 14 пт. Как улучшить?
  1. Уменьшить число слайдов до 8-10 — оставить только ключевые.
  2. Увеличить шрифт до 24-28 пт. Если не влезает — сократить текст.
  3. Заменить «стены текста» на схемы, графики, изображения.
  4. Вынести детали в заметки докладчика (Вид → Заметки).
  5. Применить единый стиль: 1-2 шрифта, 2-3 цвета, единый макет.
Задача 2. В чём разница между анимацией и переходом?
Переход — эффект между слайдами: как один слайд сменяет другой. Настраивается один раз для слайда или для всей презентации.

Анимация — эффект внутри одного слайда: как появляется/двигается объект (текст, картинка). Настраивается для каждого объекта отдельно.

Правило: переходов немного и они одинаковые по всей презентации; анимация — только там, где она помогает.
Задача 3. Как сделать так, чтобы при показе заметки были видны только докладчику?
Использовать Режим докладчика (F5 при подключённом втором экране или проекторе).

На вашем экране: текущий слайд, следующий слайд, заметки, таймер.
На экране проектора: только текущий слайд.

Заметки вводятся в режиме Вид → Заметки под каждым слайдом.
