4Графика и формулы в документе

4.1. Вставка рисунков

Меню: Вставка → Рисунки. Источники:

  • Это устройство — файл с компьютера (JPG, PNG, SVG, GIF)
  • Стоковые изображения — библиотека Microsoft
  • Онлайн-изображения — поиск в интернете прямо из Word
  • Иконки — векторные пиктограммы
  • Screenshot / Screenshot — снимок экрана

4.2. Обтекание текстом

Обтекание — как текст располагается относительно рисунка.

Три основных типа обтекания: текст над/под рисунком; текст вокруг рисунка; рисунок за текстом.
РежимЧто делаетКогда использовать
В текстеРисунок как буква, текст не обтекаетМаленькие иконки в тексте
Вокруг рамкиТекст обходит прямоугольникИллюстрации, таблицы
По контуруТекст повторяет форму объектаФигуры сложной формы
СквозноеТекст поверх рисункаФон, логотип
За текстомРисунок под текстомПодложка, водяной знак
Перед текстомРисунок поверх текстаАкцент, стикер

4.3. Блок-схемы

Word умеет рисовать блок-схемы через Вставка → Фигуры. Основные блоки:

ФигураСмысл
ПрямоугольникДействие / процесс
РомбУсловие / ветвление
ПараллелограммВвод / вывод данных
ОвалНачало / конец
СтрелкаНаправление потока
Пример блок-схемы: поиск максимума из двух чисел.

4.4. Научные формулы

Для формул в Word используется редактор уравнений:

  • Горячая клавиша: Alt+= — открыть редактор формул
  • Меню: Вставка → Уравнение
  • Символы: дроби, интегралы, суммы, матрицы, индексы
Как набрать формулу
Открыть редактор (Alt+=) → ввести: x = (-b ± √(b^2 - 4ac)) / (2a) → Word сам преобразует в красивую формулу: $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$ Пробел отделяет части формулы. Коды:
  • ^ — верхний индекс (степень)
  • _ — нижний индекс
  • / — дробь
  • \sqrt — корень
  • \int — интеграл
  • \sum — сумма

4.5. Слои и порядок

Если несколько объектов пересекаются — важен порядок слоёв:

  • Правый клик на объекте → На задний план / На передний план
  • Или Формат → Упорядочить

4.6. Подложка

Подложка — картинка или текст за основным содержимым (например, логотип или слово «ЧЕРНОВИК»).

  • Меню: Дизайн → Подложка
  • Готовые варианты или своя картинка
  • Настройка прозрачности и расположения

Практическая работа №9

🔧 ПР №9 · Рисунки, блок-схема, формула 60 мин
Задача: научиться вставлять рисунки с разным обтеканием, строить блок-схему и набирать формулы.

Часть 1. Рисунки и обтекание

  1. Создайте новый документ.
  2. Наберите 3 абзаца произвольного текста.
  3. Вставьте любое изображение с компьютера: Вставка → Рисунки → Это устройство.
  4. Установите обтекание «Вокруг рамки».
  5. Перетащите картинку вправо — текст должен обтекать её слева.
  6. Поменяйте обтекание на «За текстом» и добавьте полупрозрачность — получилась подложка.

Часть 2. Блок-схема

  1. На новой странице постройте блок-схему алгоритма «Большее из двух чисел»:
    • Овал «Начало»
    • Параллелограмм «Ввести a, b»
    • Ромб «a > b ?»
    • Два прямоугольника «max = a» и «max = b»
    • Овал «Конец»
  2. Соедините стрелками. Условие «да» идёт к «max = a», «нет» — к «max = b».
  3. Сгруппируйте всю схему в один объект: выделите все элементы → правый клик → «Группировать».

Часть 3. Формулы

  1. На новой странице заголовок «Формулы» (стиль «Заголовок 1»).
  2. Наберите 3 формулы через Alt+=:
    • Квадратное уравнение: $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
    • Площадь круга: $S = \pi R^2$
    • Сумма ряда: $\sum_{i=1}^{n} \frac{1}{i^2}$
  3. Пронумеруйте формулы справа от каждой (обычным текстом: (1), (2), (3)).
Результат: документ practice-word-graphics.docx с 3 частями. Сохранить в PDF.

Вопросы для самопроверки

Задача 1. Рисунок перекрывает текст. Как это исправить?
Правый клик на рисунке → Обтекание текстом → выбрать «Вокруг рамки» или «В тексте».

Если нужно оставить рисунок поверх текста, но текст должен быть виден — уменьшите прозрачность картинки: Формат рисунка → Прозрачность.
Задача 2. Как вставить формулу площади круга с красивой записью?
Alt+= → набрать: S = \pi R^2 → Enter. Word сам отрисует:
$$S = \pi R^2$$ Символ π (греческая пи) можно вставить из панели «Символы» в редакторе формул или набрать \pi.
Задача 3. Как сгруппировать несколько фигур в блок-схеме, чтобы двигать их вместе?
  1. Выделите все фигуры — зажмите Ctrl и кликайте по каждой.
  2. Правый клик на любой из них → Группировать → Группировать.
Теперь вся схема — один объект. Чтобы разгруппировать: правый клик → Группировать → Разгруппировать.
