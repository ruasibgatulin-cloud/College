2Текстовый процессор — основы работы

Текстовый процессор — программа для создания, редактирования и форматирования документов. Основные: Microsoft Word, Google Docs, LibreOffice Writer.

2.1. Структура документа

Документ состоит из вложенных элементов:

  • Символ — буква, цифра, знак препинания
  • Слово — последовательность символов между пробелами
  • Абзац — заканчивается нажатием Enter
  • Страница — ограничена форматом (A4, Letter)
  • Раздел — часть документа со своими колонтитулами и настройками страницы
  • Документ — весь файл целиком

2.3. Создание и сохранение

  • Новый документ: Ctrl+N
  • Сохранить: Ctrl+S
  • Сохранить как: Ctrl+Shift+S
  • Форматы:
    • .docx — современный формат Word (рекомендуется)
    • .doc — устаревший, но для совместимости
    • .pdf — для рассылки и печати (не редактируется)
    • .txt — только текст, без форматирования
    • .rtf — универсальный с сохранением форматирования

Горячие клавиши выравнивания

  • Ctrl+L — по левому краю
  • Ctrl+E — по центру
  • Ctrl+R — по правому краю
  • Ctrl+J — по ширине
Стандарты оформления (для рефератов, курсовых)
  • Шрифт: Times New Roman, 14 пт
  • Междустрочный: 1,5
  • Выравнивание: по ширине
  • Абзацный отступ: 1,25 см
  • Поля: левое 3 см, правое 1,5 см, верхнее и нижнее 2 см
  • Нумерация страниц: со 2-й или 3-й страницы

2.7. Работа со страницами

  • Параметры страницы: Макет → Поля, размер A4 (210×297 мм)
  • Ориентация: книжная или альбомная
  • Размер полей: настраивается для всего документа или отдельных разделов
  • Колонки: Макет → Колонки (2-3 колонки для газетного вида)

Практические работы №2-5

🔧 ПР №2 · Структура экрана и создание документа 30 мин
Задача: открыть Word, создать документ, сохранить его под своим именем.
  1. Запустите Word (или Google Docs).
  2. Изучите интерфейс: где лента, где строка состояния, где линейка.
  3. Создайте новый документ: Ctrl+N.
  4. Наберите текст:
    «Это мой первый документ в Word. Я изучаю информационные технологии. Сохраняю файл с расширением .docx.»
  5. Сохраните: Ctrl+S, имя файла — practice-02-Фамилия.docx.
Результат: файл сохранён, имя с вашей фамилией.
🔧 ПР №3 · Редактирование текста 30 мин
Задача: освоить выделение, копирование, вставку, поиск и замену.
  1. В документе из ПР №2 выделите слово двойным кликом.
  2. Выделите весь абзац тройным кликом.
  3. Скопируйте текст: Ctrl+C, перейдите в конец и вставьте: Ctrl+V.
  4. Найдите слово «Word» через Ctrl+F.
  5. Замените слово «информационные» на «цифровые»: Ctrl+H.
  6. Отмените последнее действие через Ctrl+Z и верните — Ctrl+Y.
🔧 ПР №4 · Форматирование символов 30 мин
Задача: применить разные шрифты, размеры, начертания.
  1. Наберите три строки текста.
  2. Первую строку оформите шрифтом Arial, 16 пт, жирным, по центру.
  3. Вторую — Times New Roman, 14 пт, курсивом, по левому краю.
  4. Третью — Calibri, 12 пт, подчёркнутым, по правому краю.
  5. На четвертой строке: примените выделение цветом и цветной текст.
  6. Проверьте результат в режиме предпросмотра (Ctrl+P).
🔧 ПР №5 · Форматирование абзацев 30 мин
Задача: применить разные выравнивания, отступы и интервалы.
  1. Скопируйте в документ любой текст из интернета (3-4 абзаца).
  2. Установите выравнивание по ширине: Ctrl+J.
  3. Установите абзацный отступ 1,25 см.
  4. Установите междустрочный интервал 1,5.
  5. Первый абзац — сделайте по центру, с отступом.
  6. Покажите непечатаемые символы (Ctrl+Shift+8) — проверьте, нет ли лишних пробелов.

Вопросы для самопроверки

Задача 1. Как выделить несмежные фрагменты текста?
Зажмите Ctrl и выделяйте мышью разные фрагменты. Отпустите Ctrl — все они останутся выделенными.

Затем можно разом применить форматирование или скопировать (Ctrl+C).
Задача 2. Что произойдёт, если поставить курсор в середине абзаца и нажать Enter?
Абзац разорвётся на два. Второй абзац унаследует форматирование первого.

Если хотите добавить пустую строку без создания нового абзаца — используйте Shift+Enter (мягкий перенос).
Задача 3. Как убрать двойные пробелы во всём документе?
Поиск и замена (Ctrl+H):
  1. Найти: два пробела (нажмите пробел дважды)
  2. Заменить на: один пробел
  3. Нажимайте «Заменить все» до тех пор, пока Word не сообщит, что замен не найдено.
Затем включите непечатаемые символы (Ctrl+Shift+8) — проверьте результат.
Задача 4. В чём разница между Ctrl+Enter и обычным Enter?
Enter — новый абзац. Word добавляет интервал до/после абзаца согласно стилю.

Ctrl+Enter — принудительный разрыв страницы. Текст переносится на новую страницу сразу, независимо от того, сколько места осталось на текущей.

Такой разрыв виден как -----разрыв страницы----- при включённых непечатаемых символах.
Итоговое задание по разделу
Создайте документ practice-word-basics.docx, который содержит:
  1. Заголовок (по центру, 16 пт, жирный): «Отчёт по практическим работам №2-5»
  2. Вашу фамилию и группу под заголовком (по центру, курсив)
  3. 4 абзаца текста на тему «Зачем мне нужны ИТ в профессии программиста»
  4. Оформление: Times New Roman 14, междустрочный 1,5, выравнивание по ширине, отступ первой строки 1,25 см
  5. В конце — раздел «Что я узнал» списком из 5 пунктов (обычный маркированный список)
Сохранить в формате .docx и .pdf. Сдать оба файла.
