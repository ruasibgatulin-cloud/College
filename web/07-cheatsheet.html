        </div>
        <div class="card">

      </div>

    <div class="container">

    </div>
  </footer>

  <script src="script.js"></script>
</body>
</html>

Готовый CSS-шаблон

/* style.css — базовый шаблон для сайта */

/* Сброс */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

html { scroll-behavior: smooth; }

body {
  font-family: 'Inter', -apple-system, 'Segoe UI', sans-serif;
  font-size: 16px;
  line-height: 1.6;
  color: #1c2331;
  background: #f7f8fb;
}

/* Контейнер для центрирования */

  max-width: 1100px;
  margin: 0 auto;
  padding: 0 20px;
}

/* Шапка */

  background: #fff;
  border-bottom: 1px solid #e5e8ef;
  position: sticky;
  top: 0;
  z-index: 100;
  padding: 16px 0;
}

  display: flex;
  justify-content: space-between;
  align-items: center;
  flex-wrap: wrap;

│   └── style.css       # стили

Чек-лист перед публикацией

Проверьте перед тем, как выкладывать сайт
  • ☐ Все ссылки работают (нет # вместо реальных страниц)
  • ☐ Изображения загружаются, у всех есть alt
  • ☐ Заголовок страницы (<title>) осмысленный
  • ☐ Есть meta viewport для адаптивности
  • ☐ Сайт корректно отображается на телефоне (F12 → режим устройства)
  • ☐ Нет ошибок в консоли браузера (F12 → Console)
  • ☐ Формы валидируются (пустые поля не отправляются)
  • ☐ Тексты проверены на опечатки
  • ☐ Favicon (иконка вкладки) добавлен
  • ☐ Сайт открывается по ссылке у других людей
