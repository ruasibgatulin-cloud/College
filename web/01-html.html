1HTML — структура веб-страницы

HTML (HyperText Markup Language) — язык разметки, который описывает структуру страницы: что здесь заголовок, что параграф, что картинка. HTML не отвечает за красоту — за это отвечает CSS.

1.1. Минимальная страница

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Моя первая страница</title>
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это моя первая веб-страница.</p>
</body>
</html>
Сохраните в файл index.html и откройте в браузере — увидите заголовок и текст.

1.2. Структура документа

В <head> — информация о странице (невидимая). В <body> — всё, что видит пользователь.

1.3. Основные теги

Текст

ТегЗначение
<h1> — <h6>Заголовки от самого важного (h1) до самого мелкого (h6)
<p>Параграф (абзац)
<strong>Важный текст (жирный по смыслу)
<em>Акцент (курсив по смыслу)
<br>Перенос строки (одиночный тег)
<hr>Горизонтальная линия-разделитель
<blockquote>Цитата (блок)
<code>Код в строке текста
<pre>Форматированный текст (сохраняет пробелы)
<h1>Заголовок страницы</h1>
<h2>Подзаголовок раздела</h2>
<p>Это обычный <strong>параграф</strong> с <em>выделением</em>.</p>
<blockquote>
  «Простота — высшая ступень искусства.»
</blockquote>
<p>Формула воды: <code>H₂O</code>.</p>

Списки

<!-- Маркированный список -->
<ul>
  <li>Яблоко</li>
  <li>Банан</li>
  <li>Апельсин</li>
</ul>

<!-- Нумерованный список -->

  <li>Найти ошибку</li>
  <li>Исправить</li>
</ol>

<!-- Вложенный список -->
<ul>
  <li>Фрукты
    <ul>
      <li>Яблоко</li>
      <li>Груша</li>
    </ul>
  </li>

</ul>

Ссылки

<!-- Обычная ссылка -->
<a href="https://example.com">Внешний сайт</a>

<!-- Ссылка на другую страницу сайта -->
<a href="about.html">О нас</a>

<!-- Ссылка на раздел этой же страницы -->
<a href="#contact">Контакты</a>

<!-- Открыть в новой вкладке -->
<a href="https://example.com" target="_blank">Откроется в новой вкладке</a>

<!-- Ссылка на email -->
<a href="mailto:info@example.com">Написать нам</a>

<!-- Ссылка на телефон -->
<a href="tel:+79991234567">Позвонить</a>

Изображения

<!-- Простое изображение -->
<img src="images/photo.jpg" alt="Описание фото">

<!-- С заданными размерами -->
<img src="photo.jpg" alt="Фото" width="400" height="300">

<!-- Адаптивное изображение -->
<img src="photo.jpg" alt="Фото" style="max-width: 100%; height: auto;">

<!-- figure — изображение с подписью -->
<figure>
  <img src="photo.jpg" alt="Закат">
  <figcaption>Закат на море, 2026</figcaption>
</figure>
alt — обязательно! Это текст, который покажется, если картинка не загрузится. И его читают скринридеры.

Формы

  <label for="name">Имя:</label>
  <input type="text" id="name" name="name" required>

  <input type="email" id="email" name="email" required>

  <!-- Пароль -->
  <label for="pwd">Пароль:</label>
  <input type="password" id="pwd" name="pwd" minlength="8">

  <!-- Число -->
  <input type="number" min="1" max="100" value="50">

  <!-- Дата -->
  <input type="date">

  <!-- Флажок -->
  <label>
    <input type="checkbox" name="agree">
    Согласен с условиями
  </label>

  <!-- Переключатель -->

    <option value="spb">СПб</option>
  </select>

  <!-- Многострочное поле -->
  <textarea name="comment" rows="5"></textarea>

  <!-- Кнопка отправки -->
  <button type="submit">Отправить</button>
</form>

1.4. Семантические теги

Семантика — использование тегов «по смыслу». Вместо <div class="header"> используем <header>. Это помогает поисковикам и скринридерам.

Типичная структура страницы с семантическими тегами.
ТегНазначение
<header>Шапка сайта или раздела
<nav>Навигация (меню)
<main>Основной контент (один на странице)
<section>Раздел с заголовком
<article>Самостоятельная статья (можно вынести отдельно)
<aside>Боковая колонка, сноски
<footer>Подвал
<div>Просто контейнер (без смысла)
<span>Контейнер для части текста

1.5. Атрибуты

Атрибут — дополнительная информация в теге. Пишется в открывающем теге через пробел: имя="значение".

src<img>, <script>Путь к файлу

1.7. Полный шаблон страницы

Этот шаблон можно использовать как стартовую точку для любого проекта.

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Описание страницы для поисковиков">
  <title>Название страницы</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>
    <h1>Название сайта</h1>
    <nav>
      <ul>
        <li><a href="#home">Главная</a></li>
        <li><a href="#about">О нас</a></li>
        <li><a href="#contact">Контакты</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <section id="home">
      <h2>Добро пожаловать</h2>
      <p>Это главная страница сайта.</p>
    </section>

    <section id="about">
      <h2>О нас</h2>
      <p>Здесь информация о компании.</p>
    </section>

    <section id="contact">
      <h2>Контакты</h2>
      <p>Email: info@example.com</p>
    </section>
  </main>

  <footer>
    <p>&copy; 2026 Мой сайт</p>
  </footer>

  <script src="script.js"></script>
</body>
</html>
Этот шаблон — основа для большинства сайтов. Дальше добавляем CSS и JS.

Практические задания

🎯 ПР №1 · Первая страница 30 мин
Задача: создать и открыть первую HTML-страницу.
  1. Создайте папку mysite на рабочем столе.
  2. Внутри создайте файл index.html (в блокноте, VS Code или Sublime).
  3. Наберите минимальный шаблон страницы.
  4. Добавьте:
    • <h1> с вашим именем
    • <p> — параграф о себе
    • <ul> — список из 3 любимых занятий
  5. Откройте файл в браузере (двойной клик).
  6. Измените заголовок страницы в <title> — обновите вкладку и увидите изменение.
🎯 ПР №2 · Портфолио 50 мин
Задача: сделать страницу-портфолио с семантическими тегами.
  1. Создайте новый файл portfolio.html.
  2. Структура:
    • <header> — имя и профессия
    • <nav> — меню с ссылками на разделы (якоря)
    • <main> — основной контент
      • <section id="about"> — о себе
      • <section id="skills"> — навыки списком
      • <section id="projects"> — 3 проекта в <article>
      • <section id="contact"> — контакты
    • <footer> — копирайт
  3. Добавьте своё фото через <img> с alt.
  4. Проверьте: клик на пункт меню — плавно переходим к разделу.
Результат: рабочая страница-портфолио. Сохраните как portfolio.html.
🎯 ПР №3 · Форма обратной связи 40 мин
Задача: сделать форму для связи.
  1. В файле portfolio.html в разделе «Контакты» добавьте форму:
    • Имя (text, required)
    • Email (email, required)
    • Тема (select с 3 вариантами)
    • Сообщение (textarea)
    • Чекбокс «Согласен на обработку»
    • Кнопка «Отправить»
  2. Каждое поле должно иметь <label>.
  3. Попробуйте отправить пустую форму — браузер не даст (HTML-валидация).

Вопросы для самопроверки

Вопрос 1. Чем HTML отличается от CSS и JavaScript?
Три разные технологии, каждая решает свою задачу:
  • HTML — структура. Что здесь есть: заголовок, параграф, картинка.
  • CSS — оформление. Как это выглядит: цвета, шрифты, размеры, положение.
  • JavaScript — поведение. Что происходит: клики, анимация, отправка данных.
Аналогия: сайт — это дом. HTML — стены и комнаты, CSS — обои и мебель, JS — электрика и водопровод (то, что работает).
Вопрос 2. Зачем нужны семантические теги, если есть div?
Смысл. <div> — просто контейнер. <header> — шапка. Для браузера визуально разницы нет, но для:
  • Поисковиков — Google понимает структуру, лучше ранжирует.
  • Скринридеров — слепые пользователи слышат «шапка сайта», «навигация», «основное содержимое».
  • Разработчиков — код читается легче: сразу видно, где шапка, где контент.
Правило: используйте семантику везде, где она уместна. <div> оставьте для случаев, когда смысла нет (обёртка для стилизации).
Вопрос 3. Почему alt у изображения обязателен?
Четыре причины:
  1. Доступность. Скринридеры читают alt слепым пользователям вместо картинки.
  2. Если картинка не загрузилась — браузер покажет alt-текст, а не пустое место.
  3. SEO. Google не «видит» картинки, но читает alt-текст — это помогает в поиске.
  4. Скорость загрузки. Пока грузится большая картинка, alt виден сразу.
Как писать alt: если картинка несёт смысл — опишите что на ней («График роста продаж»). Если картинка декоративная (просто фоновая) — alt="".
Вопрос 4. Что произойдёт, если в HTML забыть закрывающий тег?
Зависит от тега:
  • <p>, <li>, <h1> — браузер попробует восстановить сам. Обычно работает, но могут быть неожиданные эффекты.
  • <div>, <section> — браузер закроет все вложенные блоки, начиная с текущего. Вёрстка может сломаться.
  • <table>, <form> — критично. Таблица или форма могут работать неправильно.
Решение: не забывайте закрывать. В VS Code есть автозакрытие и подсветка пар. Валидатор (validator.w3.org) найдёт все незакрытые теги.
Итоговое задание по теме
Сдать папку mysite с файлами:
  1. index.html — первая страница (ПР №1)
  2. portfolio.html — портфолио с семантикой (ПР №2)
  3. contact.html или форма на портфолио (ПР №3)
  4. Папка images/ с 2-3 картинками
Все страницы должны открываться и корректно отображаться.
