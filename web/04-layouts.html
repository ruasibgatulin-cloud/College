4Современные раскладки: Flexbox и Grid

Раньше верстальщики использовали float, table и костыли. Сегодня есть два мощных инструмента: Flexbox — для одномерных раскладок, Grid — для двумерных. Вместе они решают любую задачу.

Когда что использовать
  • Flexbox — когда элементы выстраиваются в один ряд или столбец: меню, кнопки, иконки, шапка сайта.
  • Grid — когда элементы образуют сетку из строк и столбцов: галереи, дашборды, макеты страниц.
  • Вместе — часто Grid для общего макета, а Flexbox внутри блоков.

4.1. Flexbox — основы

Flexbox (Flexible Box) — модель, в которой элементы автоматически выстраиваются по одной оси и распределяют свободное место.

Flexbox: элементы выстраиваются вдоль главной оси. По умолчанию — слева направо.
.container {
  display: flex;                    /* включить Flexbox */
  flex-direction: row;              /* row (по умолчанию) | column | row-reverse | column-reverse */
  justify-content: flex-start;      /* выравнивание по главной оси */
  align-items: stretch;             /* выравнивание по поперечной оси */
  flex-wrap: nowrap;                /* nowrap | wrap | wrap-reverse */
  gap: 16px;                        /* отступы между элементами */
}

4.2. justify-content — выравнивание по главной оси

Пять значений justify-content для главной оси.

4.3. align-items — выравнивание по поперечной оси

ЗначениеЧто делает
stretchРастягивает элементы на всю высоту (по умолчанию)
flex-startПрижимает к началу поперечной оси
flex-endПрижимает к концу
centerЦентрирует
baselineВыравнивает по базовой линии текста

4.4. Управление размером элементов

.item {
  flex-grow: 1;      /* насколько элемент растёт (0 — не растёт) */
  flex-shrink: 1;    /* насколько сжимается (0 — не сжимается) */
  flex-basis: 200px; /* базовый размер до распределения */
}

/* Сокращение */
.item {
  flex: 1;           /* = flex: 1 1 0 — растянуть на всё свободное место */
}
.item-2 {
  flex: 0 0 200px;   /* фиксированные 200px, не растёт, не сжимается */
}

4.5. Практические шаблоны Flexbox

Шаблон 1. Шапка с логотипом и меню

header {
  display: flex;
  justify-content: space-between;  /* логотип слева, меню справа */
  align-items: center;             /* выровнять по вертикали */
  padding: 16px 40px;
}

nav ul {
  display: flex;
  gap: 24px;
  list-style: none;
}

Шаблон 2. Центрирование по обеим осям

.center-everything {
  display: flex;
  justify-content: center;   /* по горизонтали */
  align-items: center;       /* по вертикали */
  min-height: 100vh;         /* на всю высоту экрана */
}
Проще некуда. Раньше это было болью, теперь — две строчки.

Шаблон 3. Карточки с переносом

.cards {
  display: flex;
  flex-wrap: wrap;    /* разрешаем перенос на новую строку */
  gap: 20px;
}

.card {
  flex: 0 0 280px;    /* фиксированная ширина */
  /* или flex: 1 1 280px — растёт, но не меньше 280px */
}

Шаблон 4. Прижать футер к низу

body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
  margin: 0;
}

main {
  flex: 1;    /* занимает всё свободное место */
}

footer {
  /* прижат к низу автоматически */
}
Если контента мало — футер всё равно внизу. Если много — уезжает за пределы экрана.

4.6. Grid — основы

Grid — двумерная раскладка. Работает и со строками, и со столбцами одновременно.

Grid создаёт сетку из строк и столбцов. Элементы размещаются в ячейках.
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;    /* 3 равные колонки */
  grid-template-rows: auto auto;         /* 2 строки, высота по контенту */
  gap: 20px;                             /* отступы между ячейками */
}

/* Единица fr — fraction (доля свободного места) */
.layout-1 { grid-template-columns: 1fr 2fr; }         /* 1:2 */
.layout-2 { grid-template-columns: 200px 1fr; }       /* фикс + резина */
.layout-3 { grid-template-columns: repeat(4, 1fr); }  /* 4 равные */

4.7. Адаптивные колонки без media queries

/* Автоматически подстраивается под ширину экрана */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 20px;
}

/* Разбор: */
/* repeat() — повторяем */
/* auto-fill — сколько влезет колонок */
/* minmax(280px, 1fr) — минимум 280px, максимум — резина */
/* На широком экране: 3-4 колонки */
/* На узком: 1 колонка */
Одна строчка CSS заменяет 3 media queries. Карточки сами перестроятся.

4.8. Grid-template-areas — макет буквами

Самый наглядный способ описать раскладку страницы.

.layout {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-rows: 80px 1fr 60px;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
}

.layout > header  { grid-area: header;  }
.layout > aside   { grid-area: sidebar; }
.layout > main    { grid-area: main;    }
.layout > footer  { grid-area: footer;  }
Читается как схема: header сверху, sidebar и main в середине, footer снизу. Меняете буквы — меняется макет.

4.9. Практические шаблоны Grid

Шаблон 1. Галерея картинок

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 12px;
}

.gallery img {
  width: 100%;
  height: 200px;
  object-fit: cover;    /* обрезать, сохранив пропорции */
  border-radius: 8px;
}

Шаблон 2. Дашборд с блоками разных размеров

.dashboard {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 150px;
  gap: 16px;
}

.wide { grid-column: span 2; }     /* на 2 колонки */
.tall { grid-row: span 2; }        /* на 2 строки */
.big  { grid-column: span 2; grid-row: span 2; }  /* 2x2 */

Шаблон 3. Полный макет сайта

body {
  display: grid;
  grid-template-areas:
    "header"
    "main"
    "footer";
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
  margin: 0;
  gap: 0;
}

header { grid-area: header; }
main   { grid-area: main; }
footer { grid-area: footer; }

Вопросы для самопроверки

Вопрос 1. Чем Flexbox отличается от Grid?
Flexbox — одномерный. Элементы выстраиваются по одной оси: или в строку, или в столбец.

Grid — двумерный. Работает и со строками, и со столбцами одновременно.

Проще: Flexbox — «лента» (элементы в ряд). Grid — «таблица» (сетка).

Практическое правило: если раскладка выглядит как таблица или сетка — Grid. Если как ряд кнопок или меню — Flexbox.
Вопрос 2. Что такое главная и поперечная ось?
В Flexbox есть две оси:
  • Главная ось (main axis) — определяется flex-direction. По умолчанию — слева направо.
  • Поперечная ось (cross axis) — перпендикулярна главной.
justify-content работает по главной оси, align-items — по поперечной.

Если поменять flex-direction: column:
  • Главная ось идёт сверху вниз.
  • Поперечная — слева направо.
  • justify-content теперь выравнивает по вертикали.
Это ключевое понимание Flexbox: меняя direction, меняются оси, но свойства те же.
Вопрос 3. Что делает единица fr в Grid?
fr — fraction, доля свободного места.

Пример: 
grid-template-columns: 1fr 2fr 1fr;
Экран делится на 4 части: первая колонка — 1/4, вторая — 2/4, третья — 1/4.

Можно комбинировать с фиксированными размерами: 
grid-template-columns: 250px 1fr;
Первая — фиксированные 250px, вторая — весь остаток.
Вопрос 4. Почему repeat(auto-fill, minmax(...)) удобнее media queries?
Меньше кода. Одна строчка CSS заменяет 3-4 media queries.

Плавнее. Media queries работают «ступеньками»: при 768px одна раскладка, при 769px — другая. Между ними ничего. А auto-fill с minmax пересчитывает колонки на каждый пиксель.

Универсально. Не нужно думать о конкретных breakpoints — браузер сам решает, сколько колонок влезет.

Когда всё же нужны media queries: когда раскладка кардинально меняется — например, на мобильном сайдбар становится верхним меню, а не боковым.
