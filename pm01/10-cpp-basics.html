10Основы программирования на языке C++

C++ — компилируемый язык высокого уровня, созданный Бьёрном Страуструпом в 1979-1983 годах. Используется для системного программирования, игр, встраиваемых систем, высоконагруженных серверов. Один из немногих языков, где программист управляет памятью вручную.

10.1. Первая программа

#include <iostream>

int main() {
    std::cout << "Hello, world!" << std::endl;
    return 0;
}
Каждая C++ программа начинается с функции main. return 0 — успешное завершение.

10.4. Ветвления и циклы

// if-else
int age = 18;
if (age >= 18) {
    std::cout << "Совершеннолетний";
} else {
    std::cout << "Несовершеннолетний";
}

// switch
switch (day) {
    case 1: std::cout << "Пн"; break;
    case 2: std::cout << "Вт"; break;
    default: std::cout << "Другой";
}

// for
for (int i = 0; i < 10; i++) {
    std::cout << i << " ";
}

// while
int n = 5;
while (n > 0) {
    std::cout << n-- << " ";
}

// do-while — выполнится хотя бы раз
int x;
do {
    std::cin >> x;
} while (x <= 0);

// range-based for (C++11)
int arr[] = {1, 2, 3, 4, 5};
for (int v : arr) {
    std::cout << v << " ";
}

10.5. Массивы

// Одномерный массив
int numbers[5] = {10, 20, 30, 40, 50};
std::cout << numbers[0];   // 10
std::cout << numbers[4];   // 50

// Размер массива
int size = sizeof(numbers) / sizeof(numbers[0]);  // 5

// Двумерный массив
int matrix[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
std::cout << matrix[1][2];  // 6

// Динамический массив (C++11 — vector)
#include <vector>
std::vector<int> v = {1, 2, 3};
v.push_back(4);            // добавить в конец
v.size();                  // 4
v[0];                      // 1
v.pop_back();              // удалить последний

10.6. Функции

// Объявление (прототип)
int add(int a, int b);

// Определение
int add(int a, int b) {
    return a + b;
}

// Передача по значению (копия)
void incrementCopy(int x) { x++; }      // не изменит оригинал

// Передача по ссылке (изменит)
void incrementRef(int& x) { x++; }

// Передача по указателю
void incrementPtr(int* x) { (*x)++; }

// Значение по умолчанию
double power(double base, int exp = 2) {
    double result = 1;
    for (int i = 0; i < exp; i++) result *= base;
    return result;
}
power(5);      // 25
power(2, 10);  // 1024

// Перегрузка (overloading)
int max(int a, int b) { return a > b ? a : b; }
double max(double a, double b) { return a > b ? a : b; }

10.7. Указатели — сердце C++

Указатель p хранит адрес переменной a. Операция *p даёт значение по адресу.
int a = 5;
int* p = &a;       // p хранит адрес a

std::cout << a;    // 5
std::cout << &a;   // адрес: 0x7ffe8abc
std::cout << p;    // тот же адрес
std::cout << *p;   // 5 — значение по адресу

*p = 10;           // теперь a == 10

// Динамическое выделение памяти
int* arr = new int[10];   // массив из 10 int
arr[0] = 42;
delete[] arr;             // освободить память!

// nullptr (C++11) вместо NULL
int* ptr = nullptr;

// Проверка на nullptr
if (ptr != nullptr) {
    std::cout << *ptr;
}
⚠ Утечка памяти
Каждый new должен иметь парный delete. Если забыть — память не вернётся системе до закрытия программы. В долгоживущих серверах это фатально.

Современное решение: умные указатели (unique_ptr, shared_ptr) из C++11 — они освобождают память автоматически.

10.11. Работа с файлами

#include <fstream>
#include <string>

// Запись в файл
std::ofstream out("data.txt");
if (out.is_open()) {
    out << "Строка 1" << std::endl;
    out << "Строка 2" << std::endl;
    out.close();
}

// Чтение из файла
std::ifstream in("data.txt");
std::string line;
while (std::getline(in, line)) {
    std::cout << line << std::endl;
}
in.close();

// Дозапись в конец
std::ofstream append("data.txt", std::ios::app);
append << "Строка 3" << std::endl;
append.close();

10.12. Системы контроля версий

Git — стандарт де-факто для командной работы. Основные команды:

git init                    # создать репозиторий
git clone URL               # клонировать проект

git status                  # что изменено
git add file.txt            # добавить в staging
git add .                   # добавить всё

git commit -m "Message"     # зафиксировать
git push                    # отправить на сервер
git pull                    # получить изменения

git branch feature-x        # создать ветку
git checkout feature-x      # переключиться
git merge feature-x         # слить в текущую

git log --oneline           # история коммитов
git diff                    # что изменилось
git reset --hard HEAD       # откатить все изменения (ОСТОРОЖНО)

Файл, в котором перечислены пути, которые Git должен игнорировать: 
*.exe
*.obj
build/
.vs/
*.log
.env
Это исключает мусор из репозитория.

Вопросы для самопроверки

Вопрос 1. Чем C++ отличается от Python/JS?
  • Компилируемый. Код превращается в машинный файл, потом выполняется. Python/JS — интерпретируемые.
  • Статическая типизация. Тип проверяется на этапе компиляции.
  • Ручное управление памятью. new/delete, умные указатели. Python/JS — сборщик мусора.
  • Скорость. C++ в 10-100 раз быстрее интерпретируемых языков.
  • Сложность. Больше кода для той же задачи, но полный контроль.
C++ выбирают: игры (Unity C# использует C++ движок), ОС (Linux ядро), браузеры (Chrome, Firefox), СУБД (MySQL, PostgreSQL), встраиваемые системы, HPC.
Вопрос 2. Что такое утечка памяти и как её избежать?
Утечка памяти — ситуация, когда программа выделила память через new, но не освободила через delete. Память «теряется» — система не может её переиспользовать.

Пример: 
while (true) {
    int* p = new int[1000000];  // утечка: p теряется при следующей итерации
}
Через час работы — гигабайты утеряны.

Как избежать:
  • Использовать умные указатели (unique_ptr, shared_ptr) — они автоматически вызывают delete.
  • RAII (Resource Acquisition Is Initialization) — ресурс живёт, пока жив объект.
  • Контейнеры STL (vector, string) сами управляют памятью.
Вопрос 3. Чем отличается ссылка (&) от указателя (*)?
СвойствоСсылкаУказатель
Может быть nullНетДа
Менять адресНет (после инициализации)Да
СинтаксисКак обычная переменнаяНужно * и &

Правило: используйте ссылку, когда объект точно есть. Указатель — когда возможен null или нужна арифметика.
