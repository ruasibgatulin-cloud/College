5Событийно-управляемое программирование

Парадигма, в которой программа реагирует на события, а не выполняется линейно. Пользователь кликнул — сработал обработчик. Пришло сообщение — вызван код. Это основа всех современных GUI-приложений: Windows Forms, WPF, веб, мобильных.

5.1. Основные понятия

ПонятиеЧто этоПример
СобытиеСигнал «что-то произошло»Click, KeyPress, Load, Timer
Источник (Publisher)Объект, который генерирует событиеКнопка, форма, таймер
Подписчик (Subscriber)Кто реагирует на событиеКласс с методом OnClick
Обработчик (Handler)Метод, который вызывается при событииvoid OnButtonClick(...)
Делегат / ListenerСсылка на метод-обработчикEventHandler

5.2. Схема событийной модели

Источник генерирует событие, механизм уведомляет всех подписчиков.

5.3. Пример на C# (Windows Forms)

public partial class MainForm : Form {
    private Button btnSave;
    private TextBox txtName;

    public MainForm() {
        btnSave = new Button { Text = "Сохранить", Location = new Point(50, 100) };
        txtName = new TextBox { Location = new Point(50, 50), Width = 200 };

        // Подписка на событие
        btnSave.Click += BtnSave_Click;

        Controls.Add(btnSave);
        Controls.Add(txtName);
    }

    // Обработчик
    private void BtnSave_Click(object sender, EventArgs e) {
        MessageBox.Show($"Сохранено: {txtName.Text}");
    }
}
Классическая схема: подписка через +=, обработчик получает объект-источник и данные события.

5.5. Диалоговые окна

// Сообщение
MessageBox.Show("Текст", "Заголовок", MessageBoxButtons.OK, MessageBoxIcon.Information);

// Вопрос с ответом Да/Нет
var result = MessageBox.Show("Сохранить?", "Подтверждение", MessageBoxButtons.YesNo);
if (result == DialogResult.Yes) { /* сохранить */ }

// Открытие файла
using var dialog = new OpenFileDialog();
dialog.Filter = "Текстовые файлы|*.txt|Все файлы|*.*";
if (dialog.ShowDialog() == DialogResult.OK) {
    string path = dialog.FileName;
}

// Сохранение файла
using var save = new SaveFileDialog();
save.Filter = "Изображения|*.png;*.jpg";
if (save.ShowDialog() == DialogResult.OK) {
    string path = save.FileName;
}

5.6. Работа с несколькими формами

// Открыть вторую форму как диалог (модально — блокирует первую)
var about = new AboutForm();
about.ShowDialog();

// Открыть немодально (не блокирует)
var editor = new EditorForm();
editor.Show();

// Передать данные из второй формы в первую
var dialog = new InputForm();
if (dialog.ShowDialog() == DialogResult.OK) {
    txtName.Text = dialog.UserName;
}

5.7. Работа с графикой (GDI+)

Рисование на форме через объект Graphics:

private void Form1_Paint(object sender, PaintEventArgs e) {
    var g = e.Graphics;

    // Линия
    g.DrawLine(Pens.Black, 10, 10, 200, 10);

    // Прямоугольник
    g.DrawRectangle(Pens.Red, 50, 50, 100, 80);
    g.FillRectangle(Brushes.Yellow, 50, 50, 100, 80);

    // Эллипс
    g.DrawEllipse(Pens.Blue, 200, 50, 150, 100);

    // Текст
    g.DrawString("Hello, GDI+", new Font("Arial", 14), Brushes.Black, 50, 150);
}
Событие Paint вызывается при необходимости перерисовать форму.

5.8. Анимация через Timer

private int x = 0;
private Timer timer;

public MainForm() {
    timer = new Timer { Interval = 16 };  // ~60 fps
    timer.Tick += Timer_Tick;
    timer.Start();
}

private void Timer_Tick(object sender, EventArgs e) {
    x = (x + 5) % ClientSize.Width;
    Invalidate();  // вызывает Paint
}

private void Form1_Paint(object sender, PaintEventArgs e) {
    e.Graphics.FillEllipse(Brushes.Red, x, 100, 40, 40);
}
Мяч движется по экрану. Interval = 16 мс даёт ~60 кадров в секунду.

Вопросы для самопроверки

Вопрос 1. Что такое делегат в C# и зачем он нужен для событий?
Делегат — тип, описывающий сигнатуру метода. Это «указатель на метод» безопасным способом.

Пример: 
public delegate void EventHandler(object sender, EventArgs e);
Событие Click имеет тип EventHandler. Когда вы пишете btn.Click += OnClick, вы добавляете свой метод в список делегатов. При клике кнопка проходит по списку и вызывает все методы.

Одно событие может иметь несколько подписчиков — они все будут вызваны по очереди.
Вопрос 2. Чем отличается Show() от ShowDialog()?
Show() — немодальное окно. Открывается и не блокирует родительскую форму. Пользователь может работать с обеими формами одновременно. Родитель не ждёт закрытия.

ShowDialog() — модальное окно. Блокирует родителя, пока пользователь не закроет диалог. Возвращает DialogResult — результат нажатия кнопки.

Когда использовать: ShowDialog — для подтверждений, форм ввода (нужно дождаться ответа). Show — для независимых окон (редактор, справка).
Вопрос 3. Почему Invalidate() вызывается в Timer, а не рисуем напрямую?
В Windows Forms рисование происходит асинхронно в событии Paint. Если рисовать напрямую из Timer:
  • На графику могут наложиться другие окна — рисунок «затрётся».
  • При перекрытии окна система не знает, что надо перерисовать.
Invalidate() помечает область как «требует перерисовки». Windows сам вызовет Paint в подходящий момент — учитывая пересечения окон, обновления системы.

Для плавной анимации иногда используют DoubleBuffered = true — рисует в буфер, потом показывает целиком (без мерцания).
Вопрос 4. Как передать данные из одной формы в другую?
Три способа:
  1. Через свойство диалога: 
    var input = new InputForm();
if (input.ShowDialog() == DialogResult.OK)
    name = input.UserName;
    Во второй форме создаётся публичное свойство UserName, заполняемое по нажатию ОК.
  2. Через конструктор: 
    var dialog = new EditForm(existingData);
  3. Через события: вторая форма генерирует событие DataReady, первая на него подписана.
Способ 1 — самый распространённый для диалогов.
