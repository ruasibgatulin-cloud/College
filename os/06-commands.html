6Команды Linux и Windows

Все команды ниже можно скопировать в один клик и вставить в терминал или PowerShell. Сравнение Linux ↔ Windows дано для обеих ОС.

6.3. Работа с текстом и потоками

$ cat file.txt | wc -l                              # число строк
$ cat file.txt | sort | uniq -c | sort -rn | head  # топ повторяющихся строк
Конвейеры — сила Linux. Соединяют команды через |.
$ sed 's/old/new/g' file.txt     # заменить все old на new
$ awk '{print $1}' file.txt       # вывести первый столбец
sed и awk — мощные инструменты обработки текста.

$ curl -I https://example.com
Получить только HTTP-заголовки — быстрая проверка доступности сайта.
$ dig ya.ru +short       # быстрый ответ — только IP
$ nslookup ya.ru         # подробный вывод
DNS-диагностика.
Почему ss, а не netstat
netstat устарел и в новых дистрибутивах может отсутствовать. ss быстрее и показывает больше. Запомните: ss -tulpn — «что слушает система». Флаги: t — TCP, u — UDP, l — listen, p — PID, n — без резолва имён.

6.6. Архивация

$ tar -czvf archive.tar.gz /path/to/dir  # создать архив
$ tar -xzvf archive.tar.gz                # распаковать
$ tar -tzvf archive.tar.gz                # посмотреть содержимое
tar — стандарт для архивов в Unix. Флаги: c — create, x — extract, t — list, z — gzip, v — verbose, f — file.
$ zip -r archive.zip dir/    # создать zip
$ unzip archive.zip           # распаковать
$ unzip -l archive.zip        # список файлов внутри
Работа с ZIP — совместимо с Windows.

6.7. Работа с текстовым редактором

$ nano file.txt
Простой редактор. Сохранить — Ctrl+O, выйти — Ctrl+X.
$ vim file.txt
Мощный редактор. i — вставка, Esc — выход из режима, :wq — сохранить и выйти, :q! — выйти без сохранения.

6.8. Права sudo и работа от root

$ sudo apt update          # обновить список пакетов
$ sudo apt install htop    # установить программу
$ sudo -i                  # войти в root-сессию
sudo выполняет команду с правами root. Лучше использовать sudo для конкретных команд, а не сидеть в root-сессии.

Вопросы и задачи для самопроверки

Задача 1. Найти все .log-файлы в /var/log, которые изменялись за последние сутки. 
$ find /var/log -name '*.log' -mtime -1
-mtime -1 — изменённые за последние 24 часа.
Задача 2. Посчитать, сколько раз встречается слово ERROR в файле. 
$ grep -c "ERROR" file.log
Или: grep ERROR file.log | wc -l.
Задача 3. Скопировать все .jpg-файлы из текущей папки в /tmp/photos. 
$ mkdir -p /tmp/photos && cp *.jpg /tmp/photos/
&& — выполнить вторую команду только если первая успешна.
Практическое задание на пару
  1. Создать в ~/practice-cmds/ три файла: a.txt, b.txt, c.txt
  2. Записать в a.txt 20 строк «data line N» (использовать seq или for)
  3. Найти все файлы в папке, содержащие слово «line»
  4. Посчитать общее количество строк во всех файлах
  5. Упаковать каталог в tar.gz
  6. Скопировать архив в /tmp и распаковать там
  7. Сравнить содержимое оригинальной и распакованной папки через diff -r
