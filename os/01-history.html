1История, назначение и функции ОС

1.1. Что такое операционная система

Операционная система (ОС) — комплекс программ, который:

  • управляет ресурсами компьютера (CPU, память, устройства ввода-вывода);
  • предоставляет пользователю удобный интерфейс для работы;
  • создаёт среду для запуска и взаимодействия прикладных программ.
Аналогия
ОС — как диспетчер в аэропорту: он не перевозит пассажиров (это делают приложения), но управляет расписанием, взлётными полосами (CPU), терминалами (памятью) и связью. Без него — хаос.

1.3. Классификация ОС

По назначению

  • Универсальные — Windows, Linux, macOS — для всего
  • Серверные — Ubuntu Server, Windows Server, CentOS — обслуживание сети
  • Встраиваемые — в устройствах: роутеры, банкоматы, стиральные машины
  • Мобильные — Android, iOS — оптимизированы под тачскрин и батарею
  • Реального времени (RTOS) — FreeRTOS, QNX — критичны к задержкам (роботы, медицина)

По числу пользователей

  • Однопользовательские — Windows 10/11 для дома
  • Многопользовательские — Linux-серверы, где одновременно работают десятки людей

По числу задач

  • Однозадачные — MS-DOS (исторически)
  • Многозадачные — все современные ОС

По типу интерфейса

  • CLI (Command Line Interface) — консоль, только текст
  • GUI (Graphical User Interface) — окна, иконки, мышь
  • Смешанные — Linux с графической оболочкой + терминал

1.5. Три кита современной ОС

  • Windows — доминирует на десктопах, тесная интеграция с MS Office и Azure
  • Linux — доминирует на серверах и мобильных (Android основан на ядре Linux)
  • macOS — экосистема Apple, Unix-подобная, популярна у разработчиков

Вопросы для самопроверки

Вопрос 1. Чем серверная ОС отличается от десктопной?
  • Отсутствие GUI — экономия ресурсов, всё через консоль или веб-панель.
  • Многопользовательская работа — одновременно сотни подключений.
  • Длительная работа без перезагрузки — месяцами и годами.
  • Приоритет сетевых сервисов — веб-серверы, БД, файловые хранилища.
  • Особые требования к безопасности — SELinux/AppArmor, изоляция служб.
Вопрос 2. Зачем нужна ОС реального времени (RTOS)?
В RTOS гарантируется время реакции на событие. Если система обещает отреагировать за 1 мс — она отреагирует максимум за 1 мс, независимо от загрузки.
Это критично для:
  • Промышленных роботов
  • Медицинских приборов (кардиостимулятор)
  • Авионики и автопилотов
  • ABS/ESP в автомобилях
Примеры: FreeRTOS, QNX, VxWorks, RT-Thread.
Вопрос 3. Почему Linux стал популярен на серверах?
  • Бесплатный — не надо покупать лицензии на каждое ядро сервера.
  • Открытый исходный код — можно доработать под себя, аудит безопасности.
  • Стабильность — аптаймы в годах без перезагрузки.
  • Мощная консоль — автоматизация через shell-скрипты.
  • Разнообразие дистрибутивов — Ubuntu, Debian, CentOS, RHEL, Alpine.
  • Экосистема — Docker, Kubernetes, облачные платформы.
